# 캐논 배틀 (Canon Battle) 💣

포트리스(Fortress) 시리즈에서 영감을 받은 **턴제 2D 포격 게임**입니다.
순수 HTML5 Canvas + 자체 물리엔진으로 만들어져 서버 없이 GitHub Pages에서 바로 구동됩니다.

## 🎮 플레이

- **스테이지 모드**: 난이도가 올라가는 8개 스테이지 + 9부터 무한 전장. 진행 상황은 브라우저에 저장됩니다
- **빠른 대전**: 랜덤 테마/장애물로 AI와 1판
- **둘이 하기**: 한 기기에서 번갈아 플레이 (핫시트)

### 스테이지

| # | 테마 | 구름 장애물 | 새 | AI |
|---|---|---|---|---|
| 1 | 초원 | 없음 | – | 매우 약함 |
| 2 | 초원 | 뭉게구름 | – | 약함 |
| 3 | 사막 | 구름 띠 | 가끔 | 약함 |
| 4 | 사막 | 틈 있는 벽 | 가끔 | 보통 |
| 5 | 설원 | 계단식 | 자주 | 보통 |
| 6 | 설원 | 이동 구름 | 자주 | 보통+ |
| 7 | 화산 | 조합 | 자주 | 강함 |
| 8 | 밤하늘 | 이동 구름(두꺼움) | 자주 | 강함 |
| 9+ | 랜덤 | 랜덤(점점 두꺼워짐) | 자주 | 계속 성장 |

- **구름 장애물**: 탄이 통과는 하지만 안에 있는 동안 속도가 빠르게 줄어듭니다. 위로 넘기거나 틈을 노리세요.
- **새**: 가끔 새 떼가 지나갑니다. 탄에 맞으면 탄 속도가 절반으로 줄어듭니다.
- **테마 5종**: 초원 · 사막 · 설원 · 화산(용암) · 밤하늘

### 조작 (모바일 터치 / 키보드 겸용)

| 조작 | 터치 | 키보드 |
|---|---|---|
| 이동 | ◀ ▶ 버튼 (연료 소모) | ← → |
| 포신 각도 | ▲ ▼ 버튼 | ↑ ↓ |
| 발사 | **발사 버튼 길게 누르기** → 파워 차지 → 떼면 발사 | Space 홀드 → 릴리즈 |
| 무기 전환 | 무기 버튼 (3종 순환, 특수탄은 탄약 제한) | X |
| 방향 전환 | ↔ 버튼 | F |

### 탱크 & 무기 체계

| 탱크 | 계열 | 무기 1 (무제한) | 무기 2 | 무기 3 |
|---|---|---|---|---|
| 캐니 | 포격 | 캐논탄 | 더블샷 ×3 (2발 동시) | 철갑탄 ×2 (고데미지·소형 크레이터) |
| 미소스 | 미사일 | 로켓탄 (저중력) | 트리플 ×3 (3연발) | 유도탄 ×2 (락온 후 추진 비행) |
| 붐바 | 폭탄 | 헤비탄 (대형 크레이터) | 메가봄 ×2 (초대형 폭발) | 클러스터 ×2 (착탄 시 자탄 5발) |

무기는 게임 중 언제든(조준 중) 전환할 수 있습니다. 모든 무기의 최대 사거리는 비슷하고 궤적 모양이 다릅니다.

### 규칙

- 각도·파워·**바람**을 계산해 상대를 맞추세요. 바람은 매 턴 바뀝니다.
- 지형은 폭발로 파괴됩니다. 지형이 무너져 **물에 빠지면 즉사**!
- 폭발 넉백, 낙하 데미지 있음. 턴 제한 30초.

## 🛠 기술

- 자체 구현 물리엔진: 포물선 탄도(중력+바람 가속), 원형 크레이터 지형 파괴(하이트맵), 낙하/넉백/경사 정착
- 파워→사거리 선형화: 초기 속도를 √파워에 비례시켜 파워 50 = 최대 사거리의 50%
- AI: 각도×파워 전수 시뮬레이션으로 탄착점 예측 후 오차를 섞어 발사
- WebAudio 합성 효과음, 반응형 캔버스(모바일/데스크톱), 외부 의존성 0

## 📜 저작권

원작 포트리스(CCR)의 에셋을 사용하지 않은 팬 오마주 작품입니다. 모든 그래픽·사운드는 코드로 직접 생성했습니다.
