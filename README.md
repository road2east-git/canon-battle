# 캐논 배틀 (Canon Battle) 💣

포트리스(Fortress) 시리즈에서 영감을 받은 **턴제 2D 포격 게임**입니다.
순수 HTML5 Canvas + 자체 물리엔진으로 만들어져 서버 없이 GitHub Pages에서 바로 구동됩니다.

## 🎮 플레이

- **혼자 하기**: AI와 1:1 대결
- **둘이 하기**: 한 기기에서 번갈아 플레이 (핫시트)

### 조작 (모바일 터치 / 키보드 겸용)

| 조작 | 터치 | 키보드 |
|---|---|---|
| 이동 | ◀ ▶ 버튼 (연료 소모) | ← → |
| 포신 각도 | ▲ ▼ 버튼 | ↑ ↓ |
| 발사 | **발사 버튼 길게 누르기** → 파워 차지 → 떼면 발사 | Space 홀드 → 릴리즈 |
| 무기 전환 | 무기 버튼 (특수탄 2발 제한) | X |

### 규칙

- 각도·파워·**바람**을 계산해 상대를 맞추세요. 바람은 매 턴 바뀝니다.
- 지형은 폭발로 파괴됩니다. 지형이 무너져 **물에 빠지면 즉사**!
- 폭발 넉백, 낙하 데미지 있음. 턴 제한 30초.

## 🛠 기술

- 자체 구현 물리엔진: 포물선 탄도(중력+바람 가속), 원형 크레이터 지형 파괴(하이트맵), 낙하/넉백/경사 정착
- AI: 각도×파워 전수 시뮬레이션으로 탄착점 예측 후 오차를 섞어 발사
- WebAudio 합성 효과음, 반응형 캔버스(모바일/데스크톱), 외부 의존성 0

## 📜 저작권

원작 포트리스(CCR)의 에셋을 사용하지 않은 팬 오마주 작품입니다. 모든 그래픽·사운드는 코드로 직접 생성했습니다.
